# gazedwards.github.io

This is just a space for me to throw stuff and scream into the void. The site is generated using [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).

The `justfile` will contain all common commands to run and build the site eventually. Currently it is there to deal with an active problem with the live reload server. Simply running `just` or `just serve` will startup the development server locally on port `8000`.
